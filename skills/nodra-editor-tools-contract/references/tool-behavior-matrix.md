# Nodra editor tool behavior matrix

This matrix records current behavior implemented by `apps/web/src/App.tsx` and `interaction.ts`; “none” means no tool-specific handler was found. Pointer tolerances are screen pixels and are converted by zoom where applicable. Only visible layers participate in picking.

| Tool | Activation | Click / drag | Double-click | Hit-testing precedence | Editability and invariants |
|---|---|---|---|---|---|
| `select` | Toolbar selection; default tool. | Click selects the picked element; Shift toggles. Drag moves the selection, or marquee-selects fully enclosed visible elements from empty space. Selected resize handles resize; rotate mode rotates selected objects. | Text enters inline editing. Path, glyph, or spline switches to `forma`. A second double-click on an already selected rotatable hit enables rotation. Empty double-click clears selection/edit state. | Real node (`pickNode`) precedes topmost visible element (`pickElement`); element order is layer order then document order tie behavior. | Moves use snap/alignment feedback; previews recompute from gesture base. One completed gesture is one history transaction. |
| `forma` | Toolbar selection; text selection is cleared. | First click on a non-text/non-dimension element enters edit mode. In edit mode, node click selects a node and drag edits it; Shift toggles node selection. Marquee selects enclosed editable nodes. Node drags snap to the nearest visible non-center geometry node within 8 screen pixels, excluding the node being moved. | On an editable element, first double-click enters edit mode; in edit mode, double-clicking a segment inserts a contour node. Open paths/splines are excluded from closed-shape insertion. | Editable `pickFormaNode` first, then an edit-mode segment (`pickPathSegment`), then element hit. Text is excluded from node/segment picking. | Forma changes only the dragged node or handle; sketch, path, and spline updates must not fall through to whole-object resize. Contour edits preserve ring closure. Path/spline native nodes remain native; closed-shape segment insertion uses `insertFormaNode`. |
| `pen` | Toolbar selection; maintains a provisional first point or selected open path. | Click empty space twice creates a two-node open path. With an open selected path, click appends a line node; drag appends a cubic node. Dragging an existing anchor/control edits it. Clicking the first anchor of an open path closes it. | No tool-specific canvas double-click behavior. | Path node (`pickPathNode`) precedes path segment (`pickPathSegment`), then the pen draft/open-path fallback. | Paths require at least two nodes; closed paths add the closing segment. Drag previews are provisional and commit once; Escape/cancel clears the pen draft. Pending closure uses shared global node hover feedback and the normal tool cursor, not special close styling. |
| `spline` | Toolbar selection; creates or edits the active spline. | First two empty clicks create an open spline; later clicks append smooth nodes. With at least three nodes, clicking near the first node closes it. Drag anchors/handles edits spline geometry. | No canvas double-click behavior; `forma` handles spline double-click entry. | Spline anchor/handle overlays capture edits; otherwise the tool consumes clicks for spline construction. | Splines have at least two nodes; closing requires at least three. Handle updates mirror the opposite handle offset. Pending closure uses shared global node hover feedback and the normal tool cursor, not special close styling. |
| `text` | Toolbar selection. | Click empty space opens a text draft. Click an existing text element opens its draft for inline editing. Enter (without Shift) commits; Escape cancels; blur commits. | Existing text enters inline editing; textarea double-click is suppressed. | `pickElement` selects the existing text target. | Empty trimmed drafts are discarded. Commit preserves existing text typography/style and updates measured size; successful commit returns to `select`. Text remains editable until converted to glyphs. |
| `rectangle` | Toolbar selection; classified as a drawing tool. | First click fixes one corner; movement previews a normalized rectangle; second click commits. Existing hits are creation targets. | No tool-specific behavior. | Creation consumes the click before `pickElement`; other tools retain normal precedence. | Preview is transient; Escape/tool change cancels; commit is validated and creates a new object. |
| `ellipse` | Toolbar selection; circle behavior backed by `EllipseElement`. | First click fixes the center; movement previews a perfect circle; second click commits. Existing hits are creation targets. | No tool-specific behavior. | Creation consumes the click before `pickElement`; other tools retain normal precedence. | Width and height are always equal; preview is transient; Escape/tool change cancels. |
| `line` | Toolbar selection; drawing tool. | First click fixes a start; each click adds a segment and continues in a sketch, reusing snapped sketch nodes. While a draft exists, a cursor HUD shows the live angle and horizontal/vertical/diagonal direction. The endpoint snaps to the nearest 15° direction within a 5° tolerance; outside that tolerance the pointer remains free. Axis guides can point toward nearby visible nodes before confirmation; active guide projections are applied exactly on movement and click, while direct node snaps take precedence. Clicking the first node closes only with at least three non-collinear nodes; closed sketches remain continuable. | No tool-specific behavior. | Creation consumes the click before `pickElement`; other tools retain normal precedence. | Directional guides are active by default and can be disabled from Properties; the setting is persisted per project. Escape/tool change cancels pending creation. Closed sketches render bounded faces with fill. |
| `dimension` | Toolbar selection; starts an empty multi-click draft. | Click a node, then a different same-kind node; click again places a linear dimension. Selecting an ellipse center and rim node automatically creates a diameter dimension. For angular dimensions, click two different line bodies, then place. Mixed kinds and duplicate references are ignored. | No tool-specific behavior. | `pickDimensionTarget`: endpoint/real node first; native line or sketch-edge body is fallback, excluding line endpoints. | Linear references are nodes; ellipse center/rim pairs resolve as diameter; angular references are native lines or indexed sketch edges. Dimensions use mm, rotation 0, validated creation, and a provisional placement preview. |
| `pan` | Toolbar selection. | Pointer drag pans the viewport only; it never begins an editor gesture or changes the document. Wheel zooms around the pointer and clamps to `MIN_ZOOM`/`MAX_ZOOM`. | No tool-specific behavior. | No document hit test. | Pan is transient viewport state; no revision, persistence, or undo entry is produced. |

## Shared contract

`pointerDown` is the authoritative boundary for committing an active text draft before routing the next target. Pointer movement becomes a drag at a 3-pixel client threshold. `beginGesture` captures the document; `previewGestureFromBase` prevents cumulative pointer drift; `commitGesture` records one transaction only when preview differs from base; `cancelGesture` restores base. `dispatch` validates every resulting snapshot and leaves state, revision, persistence work, and history unchanged for failed or successful no-op commands. Selection is editor state, not domain data.

## Connections and inspector dimensions

- Explicit persisted connections are created only when a drawing click is confirmed on a snap target; hover feedback never persists a connection. Connection management/removal is not implemented and is future/unsupported.
- Stable connection addresses cover named rectangle/ellipse anchors (`nw`, `n`, `ne`, `e`, `se`, `s`, `sw`, `w`, `center`), line anchors (`start`, `end`, `center`), and path/spline node anchors and available handles.
- Document/project persistence uses schema version 5. Migration defaults missing `connections` to `[]`; validation rejects unknown elements, nodes, handles, self-connections, and duplicate connection IDs.
- Inspector Width/Height edits preserve the object/selection center when no relevant connection exists. A connected left/right/top/bottom side anchors that side; a corner address anchors both axes. Aspect lock preserves proportions while respecting connected anchors. Opposite connected sides reject a resize that would break both.
- Shape-operation selection feedback/eligibility for dimensions, lines, open paths, and open splines remains a pending follow-up; do not treat the current controls as the final contract.
