# Parametric midpoint references for open edges

Objective: Offer a calculated midpoint of every visible open edge with two defined endpoints across editing tools, and make a Line endpoint follow the referenced edge after a confirmed snap. An open curved edge uses half its traveled geometric arc length. A fully closed contour/circle/ellipse has no midpoint. Selection/Forma hover is informational and must not change click behavior; no source-edge node, split, or fake non-driving snap.

Evidence: Existing same-sketch sketch-edge midpoint is resolved in web inference and validated/projected by sketch-only midpoint constraints. The pushed `feat/line-midpoint-hover-glyph` branch adds a draft-only temporary glyph; it is not a universal reference implementation. PR #252 (`feat/line-midpoint-e2e`) remains open. The original worktree has unrelated local changes that must stay untouched.
