# Kond Design desktop

This package is the Tauri desktop shell for the existing Kond Design editor. It reuses the React composition from `apps/web` and keeps the editor packages independent of Tauri.

## Prerequisites

- Node.js >= 24
- pnpm 10.15.1 (use `corepack pnpm` when needed)
- Rust stable and the Windows WebView2/build tools for Tauri

## Development

From the repository root:

```bash
corepack pnpm install
corepack pnpm desktop:dev
```

## Build the Windows installer

```bash
corepack pnpm desktop:build
```

The NSIS installer is generated under `apps/desktop/src-tauri/target/release/bundle/nsis/`.

## Automatic updates

The Desktop app checks for updates automatically on startup in production builds. Updates are published through GitHub Releases using the Tauri updater endpoint:

```text
https://github.com/LuWebDesign/nodra/releases/latest/download/latest.json
```

The public updater key is supplied through `TAURI_UPDATER_PUBLIC_KEY` during the release build. The corresponding private key must never be committed; keep it in the release environment or GitHub Actions secrets. A release must publish the signed `latest.json`, installer, and signature artifacts generated by Tauri.

When an update is available, Kond Design asks for confirmation, downloads the signed update, and relaunches after installation.

### GitHub Actions release

`.github/workflows/desktop-release.yml` runs for tags matching `v*` and creates a draft GitHub Release. Configure these repository secrets before creating a release tag:

- `TAURI_UPDATER_PUBLIC_KEY`: public key corresponding to the updater signing key.
- `TAURI_SIGNING_PRIVATE_KEY`: private updater signing key; never commit it.
- `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`: password for the private key.

Keep the application version synchronized in the Desktop package, Rust manifest, and Tauri configuration before tagging. A tag such as `v0.1.0` produces the release artifacts for that version.

Native `.kond` open/save and file association are supported by the Desktop shell.
